# Aftercut

Clean a talking-head take for social: cut the ums and the dead air, then frame it for Reels, TikTok, Shorts, or the feed.

## Open it

In Cursor, choose Clone repo and use this public URL:

```bash
git clone https://github.com/O2M8hub/aftercut-social.git
cd aftercut-social
npm install
npm run dev
```

The dev server runs at http://localhost:4317.

Your source clips stay on your computer (for example in Downloads). Open this folder locally so those files are available to edit.
